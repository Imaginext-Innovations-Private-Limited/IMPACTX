# ScamShield AI 2.1.1 — release readiness verification

## Decision and scope
Retain the 394-message (197 per class) character TF-IDF + Linear SVM model, 0.20 margin, existing contextual rules and 11-language features. No production classifier or training-data change since v2.1.0. The new version fixes clipboard fallback feedback, consolidates research files and adds release test tooling. No large model or additional production dependency is introduced. This is a hackathon prototype, not independently validated financial safety software.

The submitted GPT.zip contains only the application (`GPT/`), including four external research scripts, but **not** the sibling `Semantic_Research/large_dataset_experiment` files, cached parquet datasets or fitted classifiers. Attempts to fetch the two Hugging Face datasets in this environment failed at DNS resolution. Consequently the external ensemble has not been trained/evaluated here. The 10,164-example combined research candidate is not deployed: it regressed on earlier selection tests and includes BSIS data whose distribution permission is not established. The newly added voting evaluator is checked with synthetic fixtures. `run_research.bat` reuses the original local cache, if present, and writes only outside the application. No external data or fitted artifacts are distributed.

## Actual verification in Linux (27 Nov 2026)
- Python 3.13.5, scikit-learn 1.8.0. Uploaded baseline: 616 tests passed; v2.1.1: 627 passed, zero failed/skipped (11 new research tests). The latter includes a miniature fixture exercise of the full ensemble fitting/splitting/evaluation/CSV pipeline, **not** external dataset results.
- Release API smoke: 6 known text regression cases, 121 basic and 121 natural cached warning endpoints available; English OCR and subsequent High Risk result passed. 242/242 bundled/basic natural-cache MP3 streams recognized by ffprobe. HTTP startup and health check passed. Python compilation and JavaScript syntax checks passed.
- Real Chromium DOM test with original HTML/JS and a local in-process HTTP bridge (direct navigation blocked): all seven groups passed. Neutral badge and safety warning, copy success/denial and complaint draft, high-risk rendering, voice play/stop controls, 5 Rescue Assistant options, mocked Groq primary/backup/outage, simulated network transitions, actual OCR upload, simulated microphone events, actual WAV metadata and upload with mocked Sarvam, all 11 response languages and Clear. No uncaught JS errors. Clipboard OS access, genuine microphone capture, live provider responses and actual human listening remain unverified.
- Real OCR with all 11 installed Tesseract language packs, one rendered synthetic scam phrase per language: 11/11 returned text, 9/11 preserved a warning. Odia and Malayalam lost the warning due to OCR errors. This is a limited functional sample, not an OCR accuracy study.
- New 44-message synthetic contrast audit (two scenario families, 11 languages): 16/22 suspicious flagged, 6 missed, 5/22 benign flagged; recall 72.73%, precision 76.19%, F1 74.42%, accuracy 75%. No exact normalized training overlap. Authored translations are not independently reviewed. Do not claim population-level accuracy; 21/55 suspicious messages still missed on the older broad evaluation.
