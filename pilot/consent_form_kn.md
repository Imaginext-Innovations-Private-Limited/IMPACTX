# ಆಸ್ಪತ್ರೆ ಬಿಲ್ ಹಂಚಿಕೊಳ್ಳಲು ಒಪ್ಪಿಗೆ (ಖರ್ಚಾ ಕವಚ ವಿದ್ಯಾರ್ಥಿ ಯೋಜನೆ)

**ಯೋಜನೆ:** ಖರ್ಚಾ ಕವಚ, ____________________ (ವಿಶ್ವವಿದ್ಯಾಲಯ)ದ ವಿದ್ಯಾರ್ಥಿ ಯೋಜನೆ, ಆಸ್ಪತ್ರೆ ಬಿಲ್‌ಗಳನ್ನು ಸರ್ಕಾರಿ ಬೆಲೆ
ಮಿತಿಗಳು ಮತ್ತು ಯೋಜನೆಯ ನಿಯಮಗಳೊಂದಿಗೆ ಪರಿಶೀಲಿಸುತ್ತದೆ.
**ಸಂಪರ್ಕ:** ____________________ (ವಿದ್ಯಾರ್ಥಿ), ____________________ (ಯೋಜನಾ ಮಾರ್ಗದರ್ಶಕರು), ಫೋನ್ ____________

ದಯವಿಟ್ಟು ಇದನ್ನು ಓದಿ, ಅಥವಾ ನಮಗೆ ಓದಿ ಹೇಳಲು ಕೇಳಿ.

1. ನಮ್ಮ ಆ್ಯಪ್ ಪರೀಕ್ಷಿಸಲು ನಿಮ್ಮ ಆಸ್ಪತ್ರೆ ಬಿಲ್‌ನ ಪ್ರತಿಯನ್ನು ಬಳಸಲು ಬಯಸುತ್ತೇವೆ. ಇದು ಸಂಶೋಧನೆ ಮತ್ತು ಕಲಿಕೆಗಾಗಿ.
   ಇದು ಕಾನೂನು ಅಥವಾ ವೈದ್ಯಕೀಯ ಸಲಹೆಯಲ್ಲ, ಮತ್ತು ನಿಮ್ಮ ಪರವಾಗಿ ಯಾವುದೇ ದೂರು ಸಲ್ಲಿಸುವುದಿಲ್ಲ.
2. ಪ್ರತಿಯನ್ನು ಇಟ್ಟುಕೊಳ್ಳುವ ಮೊದಲು ನಿಮ್ಮ ಹೆಸರು, ಫೋನ್ ಸಂಖ್ಯೆ, ವಿಳಾಸ, ಆಸ್ಪತ್ರೆ ID (UHID), ಆಧಾರ್, ABHA ಅಥವಾ
   ಕಾರ್ಡ್ ಸಂಖ್ಯೆ ಮತ್ತು ಯಾವುದೇ ಸಹಿ ಅಥವಾ ಫೋಟೋವನ್ನು ಕಪ್ಪಾಗಿಸುತ್ತೇವೆ. ಒಬ್ಬರು ಪ್ರತಿ ಪುಟವನ್ನು ಪರಿಶೀಲಿಸುತ್ತಾರೆ.
3. ಕಪ್ಪಾಗಿಸಿದ ಪ್ರತಿ ನಮ್ಮ ಯೋಜನೆಯ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತದೆ, ಅಂತರ್ಜಾಲಕ್ಕೆ ಎಂದಿಗೂ ಹಾಕುವುದಿಲ್ಲ.
   ಯೋಜನೆ ____________ (ದಿನಾಂಕ) ರಂದು ಮುಗಿದಾಗ, ಅಥವಾ ನೀವು ಕೇಳಿದರೆ ಮೊದಲೇ, ಅಳಿಸುತ್ತೇವೆ.
4. ನಿಮ್ಮನ್ನು ಗುರುತಿಸಲಾಗದ ಸಂಖ್ಯೆಗಳನ್ನು ಮಾತ್ರ ವರದಿ ಮಾಡಬಹುದು, ಉದಾ. "ಒಂದು ಬಿಲ್‌ನಲ್ಲಿ ಸ್ಟೆಂಟ್ ಸರ್ಕಾರಿ ಮಿತಿಗಿಂತ ದುಬಾರಿಯಾಗಿತ್ತು".
5. ಆ್ಯಪ್‌ಗೆ ಏನಾದರೂ ಕಂಡುಬಂದರೆ, ಅದನ್ನು ಮತ್ತು ಆಸ್ಪತ್ರೆ ಅಥವಾ ಯೋಜನೆಯನ್ನು ಹೇಗೆ ಕೇಳಬೇಕು ಎಂದು ತೋರಿಸುತ್ತೇವೆ.
   ಏನು ಮಾಡಬೇಕು ಎಂಬುದು ನಿಮ್ಮ ಆಯ್ಕೆ.
6. ನೀವು ನಿರಾಕರಿಸಬಹುದು, ಅಥವಾ ನಂತರ ಮನಸ್ಸು ಬದಲಿಸಬಹುದು, ನಿಮಗೆ ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ. ಹಿಂಪಡೆಯಲು ಮೇಲಿನ
   ಸಂಖ್ಯೆಗೆ ಕರೆ ಮಾಡಿ ನಿಮ್ಮ ಒಪ್ಪಿಗೆ ID ತಿಳಿಸಿ.

ಈ ನಿಯಮಗಳ ಮೇಲೆ ನನ್ನ ಬಿಲ್‌ನ ಪ್ರತಿಯನ್ನು ಹಂಚಿಕೊಳ್ಳಲು ನಾನು ಒಪ್ಪುತ್ತೇನೆ.
